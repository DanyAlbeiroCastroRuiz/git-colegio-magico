# 🤝 Cómo hacer un Pull Request (La Entrega Final)

Al llegar al Reto 10, se te pide que hagas un **Pull Request** para enviar tu trabajo final al Gran Mago (tu profesor). Aquí te explicamos cómo hacerlo paso a paso.

## ¿Qué es un Pull Request (PR)?
Es una "solicitud" que le haces al dueño original del repositorio (el colegio) para que revise y acepte los cambios que tú hiciste en tu propia copia (Fork). Es la forma estándar en que los desarrolladores entregan código en la vida real.

## Pasos para abrir tu Pull Request

1. **Asegúrate de haber subido todo:**
   Verifica en tu terminal que no tienes cambios pendientes y que has hecho `git push`.
   ```bash
   git status
   # Debe decir "nothing to commit, working tree clean"
   ```

2. **Ve a tu repositorio en GitHub:**
   Abre el navegador y ve a tu copia del repositorio (ej. `https://github.com/TU_USUARIO/ActividadGit`).

3. **Inicia el Pull Request:**
   Justo debajo del nombre de tu repositorio (y encima de la lista de archivos), verás un mensaje que dice algo como: *"This branch is X commits ahead of TU_USUARIO/ActividadGit"*.
   A la derecha de ese mensaje, haz clic en el botón que dice **"Contribute"** y luego en **"Open pull request"**.

   *(Si no ves ese botón, haz clic en la pestaña **"Pull requests"** en la parte superior y luego en el botón verde **"New pull request"**).*

4. **Verifica los repositorios:**
   En la pantalla que aparece, asegúrate de que:
   - **base repository:** Es el repositorio original de tu profesor.
   - **head repository:** Es tu repositorio (tu fork).

5. **Escribe el mensaje de entrega:**
   - **Título:** Escribe algo descriptivo, por ejemplo: `Entrega Final - Tu Nombre Completo`.
   - **Descripción:** Puedes dejar un comentario para el profesor. "¡Hola! Envío mis respuestas del Reto 10 y todos los retos completados."

6. **¡Envía la solicitud!**
   Haz clic en el botón verde **"Create pull request"**.

¡Felicidades! Has completado exitosamente la actividad y tu entrega está lista para ser evaluada. 🎉
